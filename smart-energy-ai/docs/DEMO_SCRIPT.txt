--------------------------------------------------------------------------------
THINGS YOU SHOULD NEVER SAY IN THE VIVA (AVOID THESE TRAPS!)
--------------------------------------------------------------------------------
❌ DO NOT SAY: "The AI calculated the total electricity bill."
   -> WHY: LLMs cannot reliably do math!
   -> SAY INSTEAD: "Deterministic Python services calculated the exact billing numbers; the LLM agent interpreted and synthesized the recommendations."

❌ DO NOT SAY: "Our anomaly detector found an electrical short-circuit in the wall."
   -> WHY: Software cannot see wiring; claiming hardware fault diagnosis invites severe cross-examination.
   -> SAY INSTEAD: "Our system detected statistical consumption anomalies and advised checking whether appliances were left operating unattended."

❌ DO NOT SAY: "Our forecasting model has 100% accuracy."
   -> WHY: No real ML model has 100% accuracy; examiners will fail you for fabricating results.
   -> SAY INSTEAD: "We measured model accuracy on holdout test data using MAE of 0.18 kWh, RMSE of 0.24 kWh, and MAPE of ~11.5%."

❌ DO NOT SAY: "We hardcoded the API key in the Python file."
   -> WHY: That is a major security flaw.
   -> SAY INSTEAD: "The API key is securely isolated in `.env`, loaded via `python-dotenv`, and masked in all application logs."

❌ DO NOT SAY: "This is just a chatbot."
   -> WHY: You built a multi-agent decision support system with ML, tariffs, and data pipelines!
   -> SAY INSTEAD: "This is a full multi-agent intelligent energy management platform with 6 specialized agents, time-series forecasting, and an interactive Gradio dashboard."

--------------------------------------------------------------------------------
COMMON MISTAKES STUDENTS MAKE DURING VIVA
--------------------------------------------------------------------------------
1. Fumbling when asked where the API key is stored. (Remember: `.env` file!)
2. Confusing kW (instantaneous power) with kWh (energy over time).
3. Not knowing the machine learning algorithm used. (Remember: `RandomForestRegressor` and `IsolationForest`!)
4. Calling the agents "functions". (Always use the term "Specialized Agents" with distinct roles!)
5. Panicking if the internet drops. (Remember: Point out our built-in **Offline Fallback Mode**!)
